# Welcome to FermiLink! 🤖

Hi there, students and enthusiasts! 👋 We're excited to have you on board. 

FermiLink is a unified platform for scientific simulations. It is tuned to perform electronic structure, molecular dynamics, electrodynamics, solid state, and self-consistent light-matter simulations.

With a simple prompt, we can generate input files, start a simulation, and plot results together.

## Advanced usage 🚀

- Type in `/package list` in the chat box for exploring the supported packages in this platform.
- Type in `/package use <package>` in the chat box for enforcing the use of this computational package.

## Free for academia

This is a free service for academic use only. We might modify the daily useage limits depending on the user number of this service.

Heavy users should consider deploying this open-source service at your own laptop, workstation, or HPC cluster.
